# Внутрипрограммные подсказки о неочевидных функциях (идея)

Статус: идея записана, не реализовано. Обсуждается куда вынести.

## Проблема

Фичи накапливаются, а узнать о них можно только из исходников:
вставка заметки из буфера обмена, клиппер (`--control --clipboard`
+ глобальный хоткей ОС), MCP (`--mcp-ro` / `--mcp-rw`), гибридный
портабл, синхронизация с MyTetroid, двойной клик по метке, Shift+Tab,
открытие картинки во внешней программе и выбором программы,
`id`/`dir` в свойствах записи и прочие. Нужна точка входа,
которую пользователь реально найдёт.

## Кандидаты на размещение

### A. Отдельный пункт меню между «Темы» и «Справка»

Например «Возможности» — диалог-карточки: что умеет программа,
по клику переход в нужные настройки или показ примера команды.
Плюсы: одно центральное место, легко найти, легко расширять.
Минусы: меню открывают редко; подсказка оторвана от места действия.

### B. Иконки (i) в пунктах настроек рядом с фичами

Контекстно: человек настраивает клиппер и тут же читает как им
пользоваться. Плюсы: подсказка ровно там где нужна. Минусы: надо
пройтись по всем диалогам; часть фич вообще без настроек
(двойной клик, Shift+Tab) — им это не поможет.

### C. QWhatsThis (встроенный «?» в Qt)

Режим «что это»: кнопка «?» в заголовке диалога или Shift+F1,
клик по виджету — всплывает пояснение. Уже есть в Qt, кода на
виджет одна строка `setWhatsThis()`, переводы через обычный `tr()`.
Плюсы: нативно, дёшево, контекстно. Минусы: про режим «?» тоже
надо как-то узнать; не покрывает фичи без виджетов (CLI, хоткеи ОС).

### D. «Совет дня» / тур при первом запуске

Привлекает внимание, но раздражает и быстро пролистывается.
Как основной механизм не годится, как дополнение — возможно позже.

### E. Тултипы и строка статуса

Уже частично используются (имя картинки, «поставьте курсор»).
Плюсы: ноль нового кода, всегда под рукой. Минусы: короткие,
не заменяют объяснение «как настроить».

## Предложение

Комбинация, по этапам:

1. **QWhatsThis (C)** — базовый слой. Проставить `setWhatsThis()`
   на неочевидные виджеты настроек и тулбара: лимиты клиппера,
   формат даты, кнопки редактора без очевидного смысла.
   Дешево, переводы штатно.
2. **Пункт «Возможности» в меню (A)** — оглавление: короткие карточки
   про клиппер (с готовой командой для хоткея), MCP (пример запуска),
   портаблы, синхронизацию, метки, горячие клавиши редактора.
   Карточки со ссылками: «открыть настройки», «скопировать команду».
3. **Тултипы (E)** — дотянуть там где их нет (кнопка открытия картинки,
   колонки панели меток).

Порядок такой потому что C даёт пользу сразу и почти бесплатно,
а A — место куда всё это ссылается.

## Инвентарь фич для подсказок (дополнять)

- Клиппер: `--control --clipboard [--url]`, ветка Clipboard,
  лимиты в настройках, хоткей ОС на `start.sh --control --clipboard`.
- MCP: `mytetra --mcp-ro` / `--mcp-rw [--db-path]`, только локальный
  stdio, один писатель.
- Вставка картинок `data:`/`file:`/`http(s)` как файлов.
- Панель меток: двойной клик ищет, одинарный выделяет; колонки
  двигаются; полное имя в подсказке.
- Редактор: Shift+Tab снимает отступ; Ctrl+клик по картинке/ссылке;
  диалог выбора программы для картинки.
- Свойства записи: `id` и каталог (для отладки синхронизации).
- Глобальный поиск: фильтр-подстрока, иконки типов, диалог из панели.
- Портаблы `MyTetra-lin/win/hybrid-portable`, первый запуск без конфигов.
- Синхронизация ПК ↔ MyTetroid (отдельная ветка протокола).
- Темы default/dark, переключение на лету.
